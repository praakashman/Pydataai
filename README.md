# Python Data AI Platform

A modern data and AI platform built with Next.js, PostgreSQL, and Drizzle ORM.

## Tech Stack

- **Framework**: Next.js 16
- **Database**: PostgreSQL with Drizzle ORM
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Getting Started

```bash
npm install
npm run dev -- --webpack
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
